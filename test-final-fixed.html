✅ Исправления в этой версии:

  • Переключатель: Исправлены размеры, теперь компактный 80×32px
  • Анимация: Плавное перемещение слайдера с cubic-bezier
  • Максимум графиков: Динамический расчет для % (среднее × 2.5, мин 50%, макс 100%)
  • Читаемость: Столбцы теперь более заметны при малых процентах

Тестовые сценарии:

  1. Переключатель: Кликните "%" → слайдер должен плавно переместиться вправо
  2. Графики: Должны показать проценты с оптимальным масштабом (не 0-100%)
  3. Тултипы: При наведении должны показывать "40.0%" вместо "40.0 проблем"
  4. Обратно: Кликните "ШТ" → вернется к количеству проблем
  5. Масштаб: Для % максимум должен быть ~80-90% (не 100%)

Ожидаемые значения:

  • Влияние на бизнес (Май): Гридчина: 40% (2 из 5), Мельникова: 100% (1 из 1)
  • Мотивация (Май): Гридчина: 50% (1 из 2), Мельникова: 100% (1 из 1)
  • Клиентоцентричность (Июнь): Гридчина: 50% (1 из 2), Коровина: 100% (1 из 1)
  • Динамический максимум: Должен быть около 80-90% (не 100%)
