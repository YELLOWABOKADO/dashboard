# Структура проекта

Документация по архитектуре и организации файлов проекта "Отчет по работе групп".

## Структура проекта

```
├── index.html                  # Основной HTML файл
├── README.md                   # Основная документация
├── project_structure.md        # Структура проекта (этот файл)
├── css/
│   └── styles.css             # CSS стили
├── js/
│   └── modules/               # JavaScript модули
│       ├── app.js             # Главный модуль приложения
│       ├── tabs.js            # Управление вкладками
│       ├── filters.js         # Фильтры и валидация
│       ├── ui-helpers.js      # UI помощники
│       ├── company.js         # Модуль компании
│       ├── departments.js     # Модуль подразделений
│       └── employees.js       # Модуль сотрудников
├── docs/                      # Техническая документация
│   ├── 01_important_user_rules.md
│   ├── CHANGES_SUMMARY.md
│   ├── FINAL_IMPLEMENTATION_REPORT.md
│   ├── TESTING_INSTRUCTIONS.md
│   └── ... (другие технические документы)
├── tests/                     # Тестовые файлы
│   ├── test-collapsible.html
│   ├── test-dynamics.html
│   └── ... (другие тестовые файлы)
├── old_files/                 # Архивные файлы
├── callcenter_operator_data.json  # Данные операторов
├── operator_issues_by_day.json   # Данные по проблемам
└── rpc_details_data.json         # RPC детализация
```

## Описание модулей

### 1. `js/modules/app.js` - Главный модуль
- Инициализация приложения
- Управление активными вкладками
- Координация между модулями

### 2. `js/modules/tabs.js` - Управление вкладками
- Переключение между вкладками
- Управление состоянием активной вкладки

### 3. `js/modules/filters.js` - Фильтры и валидация
- Валидация диапазонов дат
- Работа с множественным выбором
- Обновление текста кнопок фильтров

### 4. `js/modules/ui-helpers.js` - UI помощники
- Отображение загрузки
- Показ ошибок
- Создание бейджей изменений
- Обновление информации о периодах

### 5. `js/modules/company.js` - Модуль компании
- Загрузка данных компании
- Отрисовка таблицы компании

### 6. `js/modules/departments.js` - Модуль подразделений
- Загрузка данных подразделений
- Отрисовка таблицы подразделений
- Настройка фильтров подразделений

### 7. `js/modules/employees.js` - Модуль сотрудников
- Загрузка данных сотрудников
- Отрисовка таблицы сотрудников
- Настройка фильтров сотрудников

## Как использовать

### Запуск модульной версии
1. Откройте `index-modular.html` в браузере
2. Или запустите HTTP сервер и откройте модульную версию

### Отладка конкретного модуля
1. Откройте DevTools
2. Найдите нужный модуль в Sources
3. Поставьте breakpoint в нужном месте
4. Отладьте только этот модуль

### Добавление нового модуля
1. Создайте новый файл в `js/modules/`
2. Экспортируйте функции через `window`
3. Подключите модуль в `index-modular.html`
4. Используйте функции в других модулях

## Сравнение с монолитной версией

| Аспект | Монолитная версия | Модульная версия |
|--------|------------------|------------------|
| Размер файла | 2600+ строк | ~200 строк HTML + модули |
| Отладка | Сложно найти ошибку | Ошибка локализована |
| Разработка | Один большой файл | Отдельные модули |
| Тестирование | Сложно тестировать | Модульное тестирование |
| Поддержка | Трудно поддерживать | Легко поддерживать |

## Миграция

Для полной миграции на модульную архитектуру:
1. Протестируйте `index-modular.html`
2. Убедитесь, что все функции работают
3. Переименуйте `index.html` в `index-old.html`
4. Переименуйте `index-modular.html` в `index.html`

## Организация файлов

### 📁 docs/ - Техническая документация
Содержит все MD файлы с технической документацией:
- Отчеты по изменениям и реализации
- Инструкции по тестированию  
- Детали исправлений и обновлений
- Правила пользователей

### 🧪 tests/ - Тестовые файлы
Содержит все HTML файлы для тестирования:
- Тесты коллапсируемых элементов
- Тесты динамики
- Тесты RPC функциональности

### 📦 old_files/ - Архивные файлы
Содержит устаревшие файлы, сохраненные для справки

### 📊 Файлы данных
- `callcenter_operator_data.json` - основные данные операторов
- `operator_issues_by_day.json` - данные по проблемам по дням
- `rpc_details_data.json` - детализация RPC метрик

## Решение проблем

### Если модуль не загружается
1. Проверьте консоль браузера
2. Убедитесь, что путь к модулю правильный
3. Проверьте синтаксис в модуле

### Если функция не найдена
1. Убедитесь, что модуль загружен
2. Проверьте экспорт функции через `window`
3. Проверьте порядок загрузки модулей

### Если данные не отображаются
1. Проверьте файлы данных в корне проекта
2. Убедитесь, что тестовые данные загружены
3. Проверьте соответствующий модуль (company/departments/employees)
