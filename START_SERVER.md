# Как запустить проект

Из-за политики CORS браузеры блокируют загрузку локальных JSON файлов. Нужно запустить локальный HTTP сервер.

## Способ 1: Python (если установлен)
```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000
```

Затем откройте: http://localhost:8000

## Способ 2: Node.js (если установлен)
```bash
npx http-server -p 8000
```

Затем откройте: http://localhost:8000

## Способ 3: PHP (если установлен)
```bash
php -S localhost:8000
```

Затем откройте: http://localhost:8000

## Способ 4: Встроенные данные (временное решение)
Если не можете запустить сервер, можно встроить данные прямо в код.
