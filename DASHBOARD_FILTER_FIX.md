# Исправление: Добавлен фильтр "Дашборд"

## Проблема
После создания вкладки "Динамика" отсутствовал фильтр "Дашборд", который есть в других вкладках.

## Решение
Добавлен фильтр "Дашборд" в следующие места:

### 1. Вкладка "Динамика"
```html
<div class="filter-item">
    <span class="filter-label">Дашборд:</span>
    <select id="dynDashboard">
        <option value="Автооценка" selected>Автооценка</option>
        <option value="Автооценка УАВ/ПреХард">Автооценка УАВ/ПреХард</option>
    </select>
</div>
```

### 2. Вкладка "Команда" (для единообразия)
```html
<div class="filter-item">
    <span class="filter-label">Дашборд:</span>
    <select id="empDashboard">
        <option value="Автооценка" selected>Автооценка</option>
        <option value="Автооценка УАВ/ПреХард">Автооценка УАВ/ПреХард</option>
    </select>
</div>
```

### 3. Обновлен модуль dynamics.js
Добавлена поддержка нового фильтра в функции `getDynamicsFilters()`:
```javascript
dashboard: document.getElementById('dynDashboard')?.value || 'Автооценка',
```

### 4. Обновлен тестовый файл
Добавлен фильтр "Дашборд" в `test-dynamics.html` для тестирования.
