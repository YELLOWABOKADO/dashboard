# Инструкция: Вкладка "Динамика сотрудника"

## Что было сделано

Создана новая вкладка **"Динамика сотрудника"** в самом конце списка вкладок. Эта вкладка позволяет просматривать динамику работы отдельного сотрудника по неделям или месяцам.

## Как использовать

### 1. Открытие вкладки
- Откройте файл `index.html` в браузере
- Перейдите на последнюю вкладку **"Динамика сотрудника"**

### 2. Выбор параметров

В верхней части вкладки находятся фильтры:

1. **Сотрудник** - выберите нужного сотрудника из выпадающего списка
2. **Период с** - начальная дата периода
3. **Период по** - конечная дата периода  
4. **Группировка** - выберите:
   - **Неделя** - данные будут сгруппированы по неделям
   - **Месяц** - данные будут сгруппированы по месяцам
5. **Сравнить с** (опционально) - выберите второго сотрудника для сравнения
6. Нажмите кнопку **"Обновить"**

### 3. Просмотр результатов

После нажатия "Обновить" отобразятся:

#### Информация о сотруднике
- ФИО
- Группа
- КЦ (Контакт-центр)

#### Статистика за весь период
- **Всего звонков** - общее количество звонков
- **Всего отклонений** - общее количество отклонений
- **% отклонений** - процент отклонений от общего числа звонков
- **Средний % за период** - средний процент отклонений по всем периодам

#### График динамики
Показывает изменение показателей во времени:
- **Красная линия** - процент отклонений (левая ось)
- **Синяя линия** - количество звонков (правая ось)

#### Таблица детализации
Подробная информация по каждому периоду:
- **Период** - название недели или месяца
- **Звонков** - количество звонков в периоде
- **Отклонений** - количество отклонений в периоде
- **% отклонений** - процент отклонений в периоде
- **Изменение** - изменение относительно предыдущего периода:
  - ↑ (красный) - рост отклонений (плохо)
  - ↓ (зеленый) - снижение отклонений (хорошо)
  - → - без изменений

#### Детализация по блокам (Block 0) 🆕
Три графика для анализа проблемных зон:
- **Топ-3 проблемных блока** - столбчатая диаграмма самых проблемных блоков
- **Динамика по блокам** - изменение отклонений по топ-3 блокам во времени
- **Распределение отклонений** - круговая диаграмма долей каждого блока

#### Сравнение сотрудников 🆕
Если выбран второй сотрудник в поле "Сравнить с:":
- **Сравнительная статистика** - показатели обоих сотрудников рядом
- **График сравнения динамики** - две линии на одном графике
- **График сравнения по блокам** - столбцы для каждого блока по обоим сотрудникам

## Примеры использования

### Пример 1: Просмотр динамики за 3 месяца
1. Выберите сотрудника: "Маркина И. М."
2. Период с: 2025-05-01
3. Период по: 2025-07-31
4. Группировка: Месяц
5. Нажмите "Обновить"

Результат: увидите данные по трем месяцам (май, июнь, июль)

### Пример 2: Детальный анализ по неделям
1. Выберите сотрудника: "Ермошина С. В."
2. Период с: 2025-07-01
3. Период по: 2025-07-31
4. Группировка: Неделя
5. Нажмите "Обновить"

Результат: увидите данные по каждой неделе июля

## Технические детали

### Созданные файлы
- `js/employee-dynamics-dashboard.js` - основной модуль
- `test-employee-dynamics.html` - тестовая страница
- `EMPLOYEE_DYNAMICS_FEATURE.md` - техническая документация (на английском)

### Измененные файлы
- `index.html` - добавлена новая вкладка
- `css/styles.css` - добавлены стили
- `js/modules/app.js` - добавлена инициализация модуля

### Источник данных
Модуль использует файл `callcenter_operator_data.json` с данными о звонках и отклонениях по каждому сотруднику по дням.

## Важно!

**Данные отображаются только после:**
1. Выбора сотрудника из списка
2. Нажатия кнопки "Обновить"

При первом открытии вкладки список сотрудников загружается автоматически.

## Возможные проблемы

1. **Не отображаются сотрудники в списке**
   - Проверьте, что файл `callcenter_operator_data.json` находится в корневой папке
   - Откройте консоль браузера (F12) и проверьте наличие ошибок
   - Подождите несколько секунд - данные загружаются автоматически

2. **График не отображается**
   - Убедитесь, что подключена библиотека Chart.js
   - Проверьте консоль браузера на наличие ошибок
   - Убедитесь, что вы нажали кнопку "Обновить"

3. **Данные не обновляются**
   - Убедитесь, что выбран сотрудник из списка
   - Проверьте, что период дат корректный
   - **Обязательно нажмите кнопку "Обновить"**

## Поддержка

При возникновении проблем проверьте консоль браузера (F12 → Console) на наличие ошибок.
