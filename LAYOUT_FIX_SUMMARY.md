# Исправление расположения третьего графика

## Проблема
В блоке "Динамика блоков по месяцам" третий график (Клиентоцентричность) был смещен к центру и имел нестандартные размеры по сравнению с первыми двумя графиками.

## Решение
Изменено расположение третьего графика для соответствия макету первых двух графиков.

### Изменения в CSS (css/styles.css)

**Было:**
```css
.checklist-dynamics-charts .checklist-chart-card:nth-child(3) {
    grid-column: 1 / -1; /* Третий график занимает всю ширину */
    max-width: 70%; /* Увеличиваем ширину третьего графика */
    margin: 0 auto; /* Центрируем третий график */
}
```

**Стало:**
```css
.checklist-dynamics-charts .checklist-chart-card:nth-child(3) {
    /* Третий график теперь располагается под первым графиком */
    grid-column: 1;
    grid-row: 2;
}
```

## Результат
- ✅ Третий график теперь располагается под первым графиком (левая колонка)
- ✅ Третий график имеет такие же размеры (ширину и высоту), как первые два
- ✅ Убрано центрирование третьего графика
- ✅ Сохранена сетка 2x2 для размещения трех графиков
- ✅ Мобильная версия остается без изменений (все графики в одну колонку)
