# Обновление вкладки "Динамика сотрудника" v2.0

## Новые возможности

### 1. Детализация по блокам (Block 0)

Добавлена новая секция с тремя графиками:

#### График 1: Топ-3 проблемных блока
- Показывает три блока с наибольшим количеством отклонений
- Столбчатая диаграмма
- Цветовая кодировка: красный → оранжевый → желтый

#### График 2: Динамика по блокам
- Линейный график изменения отклонений по топ-3 блокам во времени
- Позволяет отследить тренды по каждому блоку
- Разные цвета для каждого блока

#### График 3: Распределение отклонений
- Круговая диаграмма распределения отклонений по всем блокам
- Показывает долю каждого блока в общем количестве отклонений

### 2. Сравнение с другим сотрудником

Добавлен выпадающий список "Сравнить с:" в фильтрах.

#### Сравнительная статистика
Показывает рядом:
- Всего записей
- Количество отклонений
- % отклонений

Для обоих сотрудников с визуальным разделителем "VS"

#### График сравнения динамики
- Линейный график с двумя линиями (по одной для каждого сотрудника)
- Позволяет сравнить изменение % отклонений во времени
- Синяя линия - первый сотрудник
- Красная линия - второй сотрудник

#### График сравнения по блокам
- Столбчатая диаграмма с группировкой
- Сравнение % отклонений по каждому блоку Block_0_lvl
- Синие столбцы - первый сотрудник
- Красные столбцы - второй сотрудник

## Изменения в источнике данных

### Старый формат (callcenter_operator_data.json):
```json
{
  "Маркина И. М.": {
    "КЦ": "КЦ 1",
    "Группа": "Гридчина",
    "Данные": {
      "2025-05-01": {
        "Звонков": 785,
        "Отклонений": 4,
        "%": 0.51
      }
    }
  }
}
```

### Новый формат (operator_data_days.json):
```json
[
  {
    "operator": "Маркина И. М.",
    "group": "Гридчина - группа",
    "kc": "КЦ 1",
    "date": "2025-05-01",
    "Block_0_lvl": "Клиентоцентричность",
    "Block_1_lvl": "Процедуры по процессу",
    "Block_2_lvl": "Правильное проставление результата звонка",
    "Block_3_lvl": "Правильное проставление результата звонка, балл",
    "score": 0
  }
]
```

## Как использовать

### Просмотр детализации по блокам

1. Выберите сотрудника
2. Настройте период
3. Нажмите "Обновить"
4. Прокрутите вниз до секции "Детализация по блокам (Block 0)"
5. Изучите три графика:
   - Какие блоки самые проблемные
   - Как меняется ситуация по блокам во времени
   - Какова доля каждого блока в общих отклонениях

### Сравнение сотрудников

1. Выберите первого сотрудника
2. В поле "Сравнить с:" выберите второго сотрудника
3. Настройте период (одинаковый для обоих)
4. Нажмите "Обновить"
5. Прокрутите вниз до секции "Сравнение сотрудников"
6. Изучите:
   - Сравнительную статистику
   - График динамики (кто лучше/хуже и когда)
   - График по блокам (в каких блоках у кого больше проблем)

## Примеры использования

### Пример 1: Анализ проблемных зон сотрудника
```
Сотрудник: Маркина И. М.
Период: 2025-05-01 - 2025-07-31
Группировка: Месяц
Сравнить с: (не выбрано)
```

Результат:
- Видим топ-3 проблемных блока
- Отслеживаем динамику по каждому блоку
- Понимаем, на что обратить внимание в обучении

### Пример 2: Сравнение двух сотрудников
```
Сотрудник: Маркина И. М.
Сравнить с: Ермошина С. В.
Период: 2025-06-01 - 2025-06-30
Группировка: Неделя
```

Результат:
- Видим, у кого больше отклонений
- Понимаем, в какие недели были проблемы
- Определяем, в каких блоках различия наиболее значительны

### Пример 3: Мониторинг улучшений
```
Сотрудник: Кузнецова В. Ю.
Период: 2025-05-01 - 2025-07-31
Группировка: Месяц
```

Результат:
- График динамики по блокам показывает, улучшается ли ситуация
- Можно оценить эффективность обучения/коучинга
- Видно, какие блоки требуют дополнительного внимания

## Технические детали

### Новые функции в модуле:

1. `groupDataByPeriodNew()` - группировка массива данных
2. `updateEmployeeDynamicsStatsNew()` - статистика для нового формата
3. `updateEmployeeDynamicsTableNew()` - таблица для нового формата
4. `updateEmployeeDynamicsChartNew()` - график для нового формата
5. `updateBlocksAnalysis()` - анализ по блокам
6. `updateTopBlocksChart()` - график топ-3 блоков
7. `updateBlocksDynamicsChart()` - график динамики по блокам
8. `updateBlocksDistributionChart()` - график распределения
9. `updateComparison()` - сравнение сотрудников
10. `updateComparisonDynamicsChart()` - график сравнения динамики
11. `updateComparisonBlocksChart()` - график сравнения по блокам

### Новые элементы HTML:

- `empDynCompareOperator` - селект для выбора сотрудника для сравнения
- `empDynBlocksSection` - секция детализации по блокам
- `empDynComparisonSection` - секция сравнения
- 3 canvas для графиков блоков
- 2 canvas для графиков сравнения

### Новые стили CSS:

- `.charts-grid` - сетка для графиков
- `.comparison-stats-grid` - сетка для сравнительной статистики
- `.comparison-card` - карточка сотрудника
- `.comparison-vs` - разделитель "VS"

## Совместимость

- Требуется файл `operator_data_days.json` в корневой папке
- Chart.js 4.4.0 (уже подключен)
- Современные браузеры с поддержкой ES6+

## Известные ограничения

1. Сравнение работает только для одинакового периода
2. Максимум 3 блока в графике динамики (топ-3)
3. Цвета блоков фиксированы (до 6 цветов в круговой диаграмме)
