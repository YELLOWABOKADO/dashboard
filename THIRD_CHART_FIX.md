# Исправление третьего графика в блоке "Динамика блоков по месяцам"

## Задача
Исправить расположение третьего графика (Клиентоцентричность) в вкладке "Детализация по чек-листам" в блоке "Динамика блоков по месяцам". График был смещен к центру и имел нестандартные размеры.

## Выполненные изменения

### 1. Исправлены CSS стили (css/styles.css)

**Проблемный код:**
```css
.checklist-dynamics-charts .checklist-chart-card:nth-child(3) {
    grid-column: 1 / -1; /* Третий график занимает всю ширину */
    max-width: 70%; /* Увеличиваем ширину третьего графика */
    margin: 0 auto; /* Центрируем третий график */
}
```

**Исправленный код:**
```css
.checklist-dynamics-charts .checklist-chart-card:nth-child(3) {
    /* Третий график теперь располагается под первым графиком */
    grid-column: 1;
    grid-row: 2;
}
```

### 2. Результат изменений

#### До исправления:
- Третий график занимал всю ширину контейнера
- Был ограничен по ширине до 70%
- Был центрирован по горизонтали
- Имел нестандартные размеры

#### После исправления:
- ✅ Третий график располагается под первым графиком (левая колонка)
- ✅ Имеет такие же размеры (ширину и высоту), как первые два графика
- ✅ Убрано центрирование
- ✅ Соответствует общему дизайну
