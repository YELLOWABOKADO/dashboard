# Вкладка "Динамика сотрудника"

## Описание
Новая вкладка для отображения динамики работы сотрудника по неделям или месяцам.

## Функциональность

### Фильтры
1. **Сотрудник** - выпадающий список всех сотрудников
2. **Период с/по** - выбор диапазона дат
3. **Группировка** - выбор между неделями и месяцами
4. **Кнопка "Обновить"** - применение фильтров

### Отображаемая информация

#### 1. Информация о сотруднике
- ФИО
- Группа
- КЦ

#### 2. Статистические карточки
- Всего звонков за период
- Всего отклонений за период
- % отклонений (общий)
- Средний % за период

#### 3. График динамики
Двухосевой линейный график:
- Левая ось: % отклонений (красная линия)
- Правая ось: Количество звонков (синяя линия)
- По оси X: периоды (недели или месяцы)

#### 4. Таблица детализации
Колонки:
- Период (название недели/месяца)
- Звонков (количество)
- Отклонений (количество)
- % отклонений
- Изменение (относительно предыдущего периода)

### Особенности
- Изменение показывается стрелками: ↑ (рост), ↓ (снижение), → (без изменений)
- Рост отклонений выделяется красным цветом
- Снижение отклонений выделяется зеленым цветом
- Все секции сворачиваемые

## Источник данных
Модуль использует файл `callcenter_operator_data.json` со структурой:
```json
{
  "Имя Сотрудника": {
    "КЦ": "КЦ 1",
    "Группа": "Название группы",
    "Данные": {
      "2025-05-01": {
        "Звонков": 785,
        "Отклонений": 4,
        "%": 0.51
      }
    }
  }
}
```

## Использование

1. Откройте главную страницу `index.html`
2. Перейдите на вкладку "Динамика сотрудника" (последняя вкладка)
3. Выберите сотрудника из выпадающего списка
4. Настройте период и группировку
5. Нажмите "Обновить"

## Тестирование
Для быстрого тестирования откройте `test-employee-dynamics.html` в браузере.
