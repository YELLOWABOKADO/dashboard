# Документация проекта "Отчет по работе групп"

## 📋 Обзор проекта

**Назначение**: Веб-приложение для анализа работы операторов колл-центров с отображением метрик по компании, подразделениям и сотрудникам.

**Текущий статус**: ✅ Работает в двух архитектурах - монолитной и модульной

---

## 🏗️ Архитектуры проекта

### 🔄 Доступные версии

| Версия | Файл | Описание | Статус |

## 📊 Данные и API

### Источники данных
- **`callcenter_operator_data.json`** - основные данные операторов
  - Размер: ~169KB, 8633 строки
  - Операторы: 21 оператор
  - Период: май-июль 2025
  - КЦ: КЦ 1, КЦ 2
  - Группы: Гридчина, Сычева, Мельникова, Коровина

- **`rpc_details_data.json`** - детализация RPC
  - Размер: ~3KB
  - Типы оценок: Д, П, Р, Т/Л
  - Период: июнь-июль 2025

### API функции (`real-data-processor.js`)
```javascript
// Загрузка данных
loadOperatorData()          // Загрузка данных операторов
loadRpcDetailsData()        // Загрузка RPC детализации

// Получение обработанных данных
getCompanyData(startDate, endDate, granularity, callCenter)
getDepartmentsData(startDate, endDate, granularity, callCenter, selectedDepartments)
getEmployeesData(startDate, endDate, granularity, callCenter)
getRpcDetailsData(startDate, endDate, granularity, callCenter)

// Утилиты
getPreviousPeriod(startDate, endDate, granularity)
aggregateDataForPeriod(data, startDate, endDate)
getDateRange(startDate, endDate)
```

## 🔧 Функциональность

### Вкладки
1. **Компания** - сводные данные по всем КЦ с RPC детализацией
2. **Подразделения** - данные по группам операторов
3. **Команда** - данные по отдельным операторам

### Фильтры
- **Период**: Выбор начальной и конечной даты
- **Режим отображения**: День (макс 1 день), Неделя (макс 7 дней), Месяц (макс 31 день)
- **КЦ**: Все КЦ, КЦ 1, КЦ 2
- **Группы**: Множественный выбор групп (только для подразделений)

### Метрики
- **Оценено звонков** - общее количество обработанных звонков
- **Отклонений выявлено** - количество найденных нарушений
- **% отклонений** - процент нарушений от общего количества звонков
- **Изменения** - процентное изменение относительно предыдущего периода

## 🐛 Отладка и решение проблем

### Общие проблемы

#### CORS ошибки
**Проблема**: `Access to fetch at 'file://...' from origin 'null' has been blocked by CORS policy`
**Решение**: Запустите HTTP сервер
```bash
python3 -m http.server 8000
```

#### Функции не найдены
**Проблема**: `getPreviousPeriod is not defined`
**Решение**: 
1. Проверьте загрузку `real-data-processor.js`
2. Убедитесь, что используете HTTP сервер
3. Проверьте консоль на ошибки

#### Данные не отображаются
**Проблема**: Пустые таблицы или "Загрузка данных..."
**Решение**:
1. Проверьте Network tab в DevTools
2. Убедитесь, что JSON файлы загружаются (статус 200)
3. Проверьте консоль на ошибки JavaScript

## 📈 Развитие проекта

### Добавление новых функций

#### В монолитную версию
1. Найдите соответствующий раздел в `index.html`
2. Добавьте код в нужное место
3. Протестируйте изменения

#### В модульную версию
1. Создайте новый модуль в `js/modules/`
2. Экспортируйте функции через `window`
3. Подключите модуль в `index-modular.html`
4. Используйте функции в других модулях

### Рекомендуемый workflow
1. **Разработка** → работайте с `index.html` (модульная версия)
2. **Отладка** → используйте DevTools для конкретных модулей
3. **Продакшн** → деплойте `index.html` с HTTP сервером
