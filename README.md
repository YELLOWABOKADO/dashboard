# Отчет по работе групп

Веб-приложение для анализа работы операторов колл-центров с отображением метрик по компании, подразделениям и сотрудникам.

## 🚀 Быстрый старт

```bash
# Запустите HTTP сервер
python3 -m http.server 8000

# Откройте в браузере
open http://localhost:8000
open http://localhost:8000/index.html
```

## 📋 Функциональность

- **3 вкладки**: Компания, Подразделения, Команда
- **Фильтры**: Период, режим отображения, КЦ, группы
- **Метрики**: Звонки, отклонения, проценты с изменениями
- **RPC детализация**: Разбивка по типам оценок (Д, П, Р, Т/Л)

## 🛠️ Технологии

- **HTML5, CSS3, JavaScript (ES6+)**
- **Модульная архитектура** - код разделен на логические модули
- **JSON API** для данных операторов и RPC детализации
- **Responsive дизайн** с современным UI

## 📁 Структура модулей

```
js/modules/
├── app.js          # Главный модуль приложения
├── tabs.js         # Управление вкладками
├── filters.js      # Фильтры и валидация
├── ui-helpers.js   # UI помощники (загрузка, ошибки, бейджи)
├── company.js      # Модуль данных компании
├── departments.js  # Модуль подразделений
└── employees.js    # Модуль сотрудников
```

## 🎯 Преимущества модульной архитектуры

- ✅ **Легкая отладка** - ошибки локализованы в конкретных модулях
- ✅ **Простая разработка** - можно работать с одним модулем независимо
- ✅ **Читаемый код** - каждый файл имеет четкую цель
- ✅ **Масштабируемость** - легко добавлять новые модули
