# Инструкции по тестированию сворачивающихся блоков

## Проблема
Блоки "Сотрудники" и "Подразделения" кликабельны, но не сворачиваются визуально.

## Исправления
1. ✅ Добавлено управление `max-height` в функцию `toggleCollapsibleSection`
2. ✅ Добавлена установка начальной высоты при инициализации
3. ✅ Добавлены функции отладки

## Тестирование

### 1. Основное приложение (index.html)
Откройте `index.html` и:
1. Перейдите на вкладку "Команда"
2. Попробуйте кликнуть на заголовки блоков:
   - "Сотрудники" 
   - "Динамика"
   - "Графики"
3. Откройте консоль браузера (F12) и выполните:
   ```javascript
   debugCollapsibleSections()  // Показать состояние всех блоков
   testToggleBlock("employeesTableHeader")  // Протестировать блок сотрудников
   forceInitCollapsible()  // Переинициализировать все блоки
   ```

### 2. Тестовая страница (test-collapsible.html)
Откройте `test-collapsible.html` для изолированного тестирования:
1. Используйте кнопки для отладки
2. Проверьте, что блоки сворачиваются плавно
3. Проверьте консоль на наличие ошибок

### 3. Отладка в консоли
Доступные функции отладки:
- `debugCollapsibleSections()` - показать состояние всех блоков
- `testToggleBlock("headerId")` - протестировать конкретный блок
- `forceInitCollapsible()` - принудительная переинициализация

## Ожидаемое поведение
1. При клике на заголовок блока:
   - Стрелочка поворачивается
   - Контент плавно сворачивается/разворачивается
   - В консоли появляются сообщения о переключении

2. Для блоков с графиками:
   - Графики перерисовываются после разворачивания
   - Высота блока корректно пересчитывается

## Если проблема остается
1. Проверьте консоль на ошибки JavaScript
2. Убедитесь, что CSS файл загружается корректно
3. Выполните `forceInitCollapsible()` в консоли
4. Проверьте, что элементы имеют правильные ID (Header/Content)
