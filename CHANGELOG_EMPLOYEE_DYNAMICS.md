# Changelog - Вкладка "Динамика сотрудника"

## Дата: 10 октября 2025

### Добавлено

#### Новая вкладка "Динамика сотрудника"
Создана новая вкладка для просмотра динамики работы сотрудника по неделям/месяцам.

**Основные возможности:**
- Выбор сотрудника из выпадающего списка
- Выбор периода дат (с/по)
- Группировка данных по неделям или месяцам
- Отображение информации о сотруднике (ФИО, группа, КЦ)
- Статистические карточки (всего звонков, отклонений, проценты)
- График динамики с двумя осями (% отклонений и количество звонков)
- Таблица детализации по периодам с отображением изменений

**Визуальные элементы:**
- Изменения показываются стрелками (↑↓→)
- Рост отклонений выделяется красным
- Снижение отклонений выделяется зеленым
- Все секции сворачиваемые

### Технические детали

**Используемые технологии:**
- JavaScript (ES6+)
- Chart.js 4.4.0 для графиков
- CSS Grid для адаптивной верстки
- Fetch API для загрузки данных

**Источник данных:**
- `callcenter_operator_data.json` - данные о звонках и отклонениях

**Алгоритмы:**
- Группировка по неделям: ISO 8601 week numbering
- Группировка по месяцам: по календарным месяцам
- Расчет изменений: разница процентов между периодами

### Тестирование

**Как протестировать:**
1. Откройте `index.html` в браузере
2. Перейдите на вкладку "Динамика сотрудника"
3. Выберите сотрудника (например, "Маркина И. М.")
4. Установите период: 2025-05-01 - 2025-07-31
5. Выберите группировку "Месяц"
6. Нажмите "Обновить"

**Альтернативный тест:**
- Откройте `test-employee-dynamics.html` для изолированного тестирования

### Известные ограничения

1. Данные доступны только за период, представленный в JSON файле
2. Первый период в таблице не имеет значения "Изменение" (нет предыдущего периода для сравнения)
3. При группировке по неделям используется ISO 8601 (неделя начинается с понедельника)

### Исправления (10 октября 2025)

**Проблема:** Выпадающий список сотрудников был недоступен

**Решение:**
- Изменена логика загрузки данных - теперь данные загружаются автоматически при первом открытии вкладки
- Добавлена проверка загрузки данных перед применением фильтров
- Убрана автоматическая фильтрация при переключении на вкладку
- Данные отображаются только после выбора сотрудника и нажатия кнопки "Обновить"
