# Изменение структуры таблицы динамики компании

## Что было изменено

Поменяли местами структуру таблицы динамики компании:

### Было (периоды как строки):
| Период | Звонков | Отклонений | % отклонений | Изменение |
|--------|---------|------------|--------------|-----------|
| Июл 2025 | 318,489 | 5,229 | 1.64% | +0.2% |
| Июн 2025 | 295,123 | 4,891 | 1.66% | -0.1% |
| Май 2025 | 287,456 | 4,756 | 1.65% | — |

### Стало (периоды как столбцы):
| Показатель | Июл 2025 | Июн 2025 | Май 2025 |
|------------|-----------|-----------|----------|
| Звонков | 318,489 | 295,123 | 287,456 |
| Отклонений | 5,229 | 4,891 | 4,756 |
| % отклонений | 1.64% | 1.66% | 1.65% |
| Изменение | +0.2% | -0.1% | — |

## Преимущества новой структуры

1. **Лучшая читаемость** - легче сравнивать показатели между периодами
2. **Компактность** - таблица занимает меньше места по вертикали
3. **Удобство анализа** - можно быстро проследить тренд каждого показателя
4. **Соответствие макету** - структура соответствует предоставленному изображению

## Техническая реализация

### Изменения в generateCompanyDynamicsTable():

1. **Заголовки таблицы**:
   - Первый столбец: "Показатель"
   - Остальные столбцы: названия периодов (динамически)

2. **Строки данных**:
   - Строка "Звонков": количество звонков по периодам
   - Строка "Отклонений": количество отклонений по периодам
   - Строка "% отклонений": процент отклонений по периодам
   - Строка "Изменение": изменение относительно предыдущего периода

3. **Логика генерации**:
   ```javascript
   // Заголовки - периоды как столбцы
   companyData.forEach(periodData => {
       tableHTML += `<th class="details-header-period">${periodData.period}</th>`;
   });
   
   // Строки - показатели
   // Звонков
   companyData.forEach(periodData => {
       tableHTML += `<td class="details-cell">${periodData.calls.toLocaleString()}</td>`;
   });
   
   // Отклонений
   companyData.forEach(periodData => {
       tableHTML += `<td class="details-cell">${periodData.deviations.toLocaleString()}</td>`;
   });
   
   // % отклонений
   companyData.forEach(periodData => {
       tableHTML += `<td class="details-cell">${periodData.percentage.toFixed(2)}%</td>`;
   });
   
   // Изменение
   companyData.forEach((periodData, index) => {
       // Логика вычисления изменения относительно предыдущего периода
   });
   ```

## Сохраненная функциональность

- ✅ Автоматическое вычисление периодов (3 месяца / 15 недель / 15 дней)
- ✅ Фильтрация по КЦ и дашборду
- ✅ Агрегация данных по всей компании
- ✅ Вычисление изменений относительно предыдущего периода
- ✅ Цветовая индикация изменений (зеленый/красный)
- ✅ Форматирование чисел с разделителями тысяч
- ✅ Адаптивная прокрутка для большого количества периодов

## Результат

Таблица динамики компании теперь имеет более удобную для анализа структуру, где:
- **Столбцы** = периоды времени
- **Строки** = показатели (звонки, отклонения, %, изменение)

Это позволяет легче отслеживать тренды каждого показателя и сравнивать данные между периодами.
