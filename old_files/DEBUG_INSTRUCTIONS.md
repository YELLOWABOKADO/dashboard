# Инструкции по отладке сворачивания

## Шаги для проверки:

### 1. Тест простой функциональности
Откройте `simple-test.html` в браузере:
- Должно работать сворачивание при клике на "Всего ▼"
- В консоли должны появляться логи

### 2. Тест с реальными стилями
Откройте `test-collapse.html` в браузере:
- Проверьте, что стили применяются правильно
- Проверьте логи в консоли

### 3. Основное приложение
Откройте `index.html` в браузере:
- Откройте консоль браузера (F12)
- Нажмите кнопку "Обновить" на вкладке "Компания"
- Проверьте логи:
  - "=== Таблица отрисована, инициализируем сворачивание ==="
  - "initTableCollapse найдена, вызываем..."
  - "=== initTableCollapse вызвана ==="
  - "Найдено expandable-row элементов: X"

### 4. Проверка кликов
- Кликните на строку "Всего ▼"
- В консоли должны появиться логи:
  - "=== handleTableRowClick вызван ==="
  - "expandableRow найден: [элемент]"
  - "targetClass: total-details"
  - "detailRows найдено: 2"

## Возможные проблемы:

1. **Скрипты не загружаются** - проверьте пути к файлам
2. **initTableCollapse не найдена** - проверьте загрузку ui-helpers.js
3. **expandableRow не найден** - проверьте HTML разметку
4. **detailRows не найдены** - проверьте классы в HTML

## Если ничего не работает:
Попробуйте добавить обработчик напрямую в консоли:
```javascript
document.querySelector('.expandable-row').addEventListener('click', function() {
    console.log('Прямой клик работает!');
});
```
