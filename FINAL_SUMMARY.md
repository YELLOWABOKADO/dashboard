5. При необходимости измените период и группировку
6. **Нажмите кнопку "Обновить"**

### Известные особенности:

1. **Первый период без изменения** - это нормально, т.к. нет предыдущего периода для сравнения
2. **Данные загружаются 1-2 секунды** - это нормально для больших JSON файлов
3. **Нужно нажимать "Обновить"** - данные не обновляются автоматически при изменении фильтров

### Если что-то не работает:

1. **Откройте консоль** (F12 → Console)
2. **Проверьте ошибки** - красные сообщения
3. **Убедитесь**, что файл `callcenter_operator_data.json` существует
4. **Попробуйте другой браузер** (Chrome, Firefox, Safari)
5. **Используйте локальный сервер** вместо file:// протокола

### Команды для запуска локального сервера:

```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000

# Node.js (если установлен npx)
npx serve

# PHP
php -S localhost:8000
```

Затем откройте: `http://localhost:8000`
