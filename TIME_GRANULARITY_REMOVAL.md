# Удаление фильтра "Режим отображения" из вкладок "Подразделения" и "Команда"

## Что было удалено

### HTML элементы (index.html):
1. **Вкладка "Подразделения"**:
   - Удален select с id `deptTimeGranularity`
   - Удален весь блок фильтра "Режим отображения"

2. **Вкладка "Команда"**:
   - Удален select с id `empTimeGranularity`
   - Удален весь блок фильтра "Режим отображения"

### JavaScript зависимости:

#### departments.js:
- Удалена переменная `granularity = document.getElementById('deptTimeGranularity').value`
- Заменена на фиксированное значение `'Месяц'` во всех функциях
- Обновлены вызовы:
  - `validateDateRange(startDate, endDate, 'Месяц')`
  - `getDepartmentsData(startDate, endDate, 'Месяц', callCenter, selectedDepartments)`

#### employees.js:
- Удалена переменная `granularity = document.getElementById('empTimeGranularity').value`
- Заменена на фиксированное значение `'Месяц'` во всех функциях
- Обновлены вызовы:
  - `validateDateRange(startDate, endDate, 'Месяц')`
  - `getEmployeesData(startDate, endDate, 'Месяц', callCenter, selectedDepartments, selectedEmployees)`
  - `timeGranularity: 'Месяц'` в объектах фильтров

## Причина изменений

Фильтр "Режим отображения" теперь используется только во вкладке "Компания" для блока динамики, где он имеет особую логику:
- **Месяц**: последние 3 месяца
- **Неделя**: последние 15 недель  
- **День**: последние 15 дней

Во вкладках "Подразделения" и "Команда" этот фильтр не нужен, так как:
- Данные отображаются в табличном виде за выбранный период
- Нет необходимости в автоматическом вычислении периодов
- Упрощается интерфейс и убираются лишние элементы
