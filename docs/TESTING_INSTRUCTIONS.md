# Инструкции по тестированию переключателя диаграмм

## Быстрое тестирование

1. Откройте файл `test-toggle.html` в браузере
2. Проверьте, что отображаются две диаграммы с переключателями
3. Нажмите на кнопки "шт" и "%" для каждой диаграммы
4. Убедитесь, что:
   - Заголовок диаграммы изменяется
   - Данные на диаграмме обновляются
   - Активная кнопка подсвечивается

## Полное тестирование

1. Откройте основной файл `index.html`
2. Перейдите на вкладку "Подразделения"
3. Разверните блок "Графики"
4. Проверьте переключатель для столбчатой диаграммы
5. Перейдите на вкладку "Команда"
6. Разверните блок "Графики"
7. Проверьте переключатель для столбчатой диаграммы

## Проверка в консоли браузера

Откройте консоль разработчика (F12) и найдите сообщения:
- `=== Проверка реализации переключателя диаграмм ===`
- Все элементы должны быть отмечены как "✓ найден"
- Все функции должны быть отмечены как "✓ найдена"
- Старые функции должны быть отмечены как "✓ удалена"

## Ожидаемое поведение

### Режим "шт" (количество)
- Заголовок: "Количество отклонений"
- Ось X: числовые значения без знака %
- Подсказки: "Отклонений: 150"

### Режим "%" (процент)
- Заголовок: "Процент отклонений"  
- Ось X: значения со знаком %
- Подсказки: "Процент: 12.50%"

## Возможные проблемы

1. **Переключатель не работает**
   - Проверьте, что файл `charts.js` загружен
   - Убедитесь, что функция `initChartToggle` вызывается

2. **Диаграмма не отображается**
   - Проверьте, что Chart.js загружен
   - Убедитесь, что canvas элементы существуют в DOM

3. **Стили переключателя не применяются**
   - Проверьте, что CSS файл загружен
   - Убедитесь, что стили для `.chart-toggle` добавлены
