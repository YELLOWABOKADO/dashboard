# Реализация блока "Динамика" во вкладке "Компания"

## Что было добавлено

### 1. Новый сворачивающийся блок "Динамика"
- Добавлен во вкладку "Компания" после таблицы сводной информации
- Блок можно сворачивать/разворачивать независимо от основной таблицы

### 2. Особая логика фильтрации

#### Для блока "Сводная информация по компании":
- ✅ Период (даты с/по)
- ❌ Режим отображения (не влияет)
- ✅ КЦ
- ✅ Дашборд

#### Для блока "Динамика":
- ❌ Период (даты с/по) - не влияет, используются автоматически вычисленные даты
- ✅ Режим отображения - определяет период и количество данных
- ✅ КЦ
- ✅ Дашборд

### 3. Автоматическое вычисление периодов

**При выборе "Месяц":**
- Показывает данные за последние 3 месяца
- Автоматически вычисляет даты от первого дня 3 месяца назад до последнего дня текущего месяца

**При выборе "Неделя":**
- Показывает данные за последние 15 недель
- Автоматически вычисляет даты от 15 недель назад до сегодня

**При выборе "День":**
- Показывает данные за последние 15 дней
- Автоматически вычисляет даты от 15 дней назад до сегодня

### JavaScript модуль (company-dynamics.js)

**Основные функции:**
- `initCompanyDynamics()` - инициализация модуля
- `loadCompanyDynamics()` - загрузка данных динамики
- `getCompanyDynamicsFilters()` - получение фильтров
- `calculateDynamicDates()` - автоматическое вычисление дат
- `aggregateCompanyData()` - агрегация данных по компании
- `generateCompanyDynamicsTable()` - генерация HTML таблицы

**Логика вычисления дат:**
```javascript
function calculateDynamicDates(timeGranularity) {
    const today = new Date();
    let startDate, endDate;
    
    switch (timeGranularity) {
        case 'Месяц':
            // Последние 3 месяца
            endDate = new Date(today.getFullYear(), today.getMonth() + 1, 0);
            startDate = new Date(today.getFullYear(), today.getMonth() - 2, 1);
            break;
        case 'Неделя':
            // Последние 15 недель
            endDate = new Date(today);
            startDate = new Date(today);
            startDate.setDate(today.getDate() - (15 * 7));
            break;
        case 'День':
            // Последние 15 дней
            endDate = new Date(today);
            startDate = new Date(today);
            startDate.setDate(today.getDate() - 15);
            break;
    }
    
    return { startDate, endDate };
}
```
