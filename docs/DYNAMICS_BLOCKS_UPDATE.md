## Функциональность

### Динамика по команде
- Показывает данные по каждому сотруднику отдельно
- Фильтрация по сотрудникам, группам, КЦ
- Отображение процента отклонений по периодам
- Показ изменений относительно предыдущего периода

### Динамика по подразделениям
- Показывает агрегированные данные по группам/подразделениям
- Суммирует данные всех сотрудников в группе
- Показывает количество сотрудников в группе
- Отображение процента отклонений по периодам
- Показ изменений относительно предыдущего периода

## Особенности реализации

### Агрегация данных по подразделениям
1. Группировка сотрудников по полю "Группа"
2. Суммирование звонков и отклонений всех сотрудников группы
3. Вычисление общего процента отклонений для группы
4. Отображение количества сотрудников в группе

### Фильтрация
- Оба блока используют одни и те же фильтры
- Фильтры применяются независимо к каждому блоку
- При изменении фильтров обновляются оба блока

### Интерфейс
- Каждый блок можно сворачивать/разворачивать независимо
- Индикаторы загрузки для каждого блока отдельно
- Разные заголовки таблиц для различения типа данных

## Результат
Теперь во вкладке "Динамика" пользователи могут видеть:
1. **Детальную динамику по каждому сотруднику** в блоке "Динамика по команде"
2. **Сводную динамику по подразделениям** в блоке "Динамика по подразделениям"

Это позволяет анализировать данные как на уровне отдельных сотрудников, так и на уровне групп/подразделений.
