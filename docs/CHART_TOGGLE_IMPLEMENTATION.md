# Реализация переключателя диаграмм

## Описание изменений

В табах "Подразделения" и "Команда" вместо двух отдельных диаграмм ("Количество отклонений" и "Процент отклонений") теперь используется одна диаграмма с переключателем между режимами отображения.

## Изменения в HTML (index.html)

### Вкладка "Подразделения"
- Удалены две отдельные диаграммы (`deviationsBarChart` и `percentageBarChart`)
- Добавлена одна объединенная диаграмма `departmentsBarChart` с переключателем
- Добавлен заголовок с id `departmentsBarChartTitle` для динамического изменения

### Вкладка "Команда"
- Удалены две отдельные диаграммы (`employeesDeviationsBarChart` и `employeesPercentageBarChart`)
- Добавлена одна объединенная диаграмма `employeesBarChart` с переключателем
- Добавлен заголовок с id `employeesBarChartTitle` для динамического изменения

### Структура переключателя
```html
<div class="chart-header">
    <h5 id="departmentsBarChartTitle">Количество отклонений</h5>
    <div class="chart-toggle">
        <button class="toggle-btn active" data-mode="count" data-target="departments">шт</button>
        <button class="toggle-btn" data-mode="percent" data-target="departments">%</button>
    </div>
</div>
```

## Изменения в CSS (css/styles.css)

Добавлены стили для переключателя:
- `.chart-header` - контейнер для заголовка и переключателя
- `.chart-toggle` - контейнер переключателя
- `.toggle-btn` - стили кнопок переключателя
- `.toggle-btn.active` - стили активной кнопки

## Изменения в JavaScript (js/modules/charts.js)

### Удаленные функции
- `createDeviationsBarChart()` - создание диаграммы количества отклонений
- `createPercentageBarChart()` - создание диаграммы процента отклонений
- `createEmployeeDeviationsBarChart()` - создание диаграммы количества отклонений сотрудников
- `createEmployeePercentageBarChart()` - создание диаграммы процента отклонений сотрудников

### Новые функции
- `initChartToggle(target)` - инициализация обработчиков переключателя
- `createDepartmentsBarChart(chartData, mode)` - объединенная функция для диаграмм подразделений
- `createEmployeesBarChart(chartData, mode)` - объединенная функция для диаграмм сотрудников

### Обновленные функции
- `initDepartmentCharts()` - теперь вызывает объединенную функцию и инициализирует переключатель
- `initEmployeeCharts()` - теперь вызывает объединенную функцию и инициализирует переключатель

## Принцип работы

1. При инициализации диаграмм данные сохраняются в глобальных переменных:
   - `window.departmentsChartData` - данные подразделений
   - `window.employeesChartData` - данные сотрудников

2. По умолчанию отображается режим "количество" (шт)

3. При клике на переключатель:
   - Обновляется активная кнопка
   - Изменяется заголовок диаграммы
   - Перерисовывается диаграмма с новыми данными

4. Режимы переключения:
   - `count` (шт) - отображает количество отклонений
   - `percent` (%) - отображает процент отклонений
