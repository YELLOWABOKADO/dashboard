## Ключевые особенности реализации

### 1. Сохранение данных
Данные диаграмм сохраняются в глобальных переменных для быстрого переключения:
- `window.departmentsChartData`
- `window.employeesChartData`

### 2. Динамическое обновление
При переключении режима:
- Обновляется заголовок диаграммы
- Перерисовывается диаграмма с новыми данными
- Изменяется активная кнопка

### 3. Совместимость
- Круговые диаграммы остались без изменений
- Существующий код продолжает работать
- Сохранена структура данных

## Режимы работы

### Режим "шт" (count)
- Отображает количество отклонений
- Заголовок: "Количество отклонений"
- Формат данных: числовые значения
- Подсказки: "Отклонений: 150"

### Режим "%" (percent)
- Отображает процент отклонений
- Заголовок: "Процент отклонений"
- Формат данных: проценты
- Подсказки: "Процент: 12.50%"
