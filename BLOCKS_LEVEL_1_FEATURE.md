# Детализация по блокам 1 уровня

## Что добавлено

Добавлен новый раздел "📈 Детализация по блокам (Block 1)" на вкладке "Динамика сотрудника", который дополняет существующий анализ по блокам 0 уровня.

## Отличия от блоков 0 уровня

### Block 0 (📊 Детализация по блокам Block 0)
- **Уровень**: Верхний уровень категоризации
- **Примеры**: "Клиентоцентричность", "Влияние на мотивацию сотрудника"
- **Топ**: 3 проблемных блока
- **График**: Круговая диаграмма (pie chart)

### Block 1 (📈 Детализация по блокам Block 1)
- **Уровень**: Более детальная категоризация внутри Block 0
- **Примеры**: "Процедуры по процессу", "Провоцирование конфликта"
- **Топ**: 5 проблемных блоков
- **График**: Кольцевая диаграмма (doughnut chart)
- **Визуализация топ-5**: Горизонтальная столбчатая диаграмма для лучшей читаемости длинных названий

## Структура блока

### 1. Топ-5 проблемных блоков
- **Тип**: Горизонтальная столбчатая диаграмма (horizontal bar chart)
- **Данные**: Количество отклонений по каждому блоку
- **Сортировка**: По убыванию количества отклонений
- **Цвета**: Градиент от оранжевого к синему (#EE964B → #7c9ff5)
- **Преимущество**: Длинные названия блоков хорошо читаются

### 2. Динамика по блокам
- **Тип**: Линейный график (line chart)
- **Данные**: Изменение количества отклонений по датам для топ-5 блоков
- **Оси**: 
  - X: Даты
  - Y: Количество отклонений
- **Легенда**: Сверху, показывает все 5 блоков
- **Цвета**: Соответствуют топ-5 диаграмме

### 3. Распределение отклонений
- **Тип**: Кольцевая диаграмма (doughnut chart)
- **Данные**: Процентное распределение всех отклонений по блокам 1 уровня
- **Легенда**: Справа, компактный размер (font-size: 11px)
- **Цвета**: Расширенная палитра Golden Fields Glow

## Технические детали

### Новые элементы HTML:

**index.html:**
```html
<div class="collapsible-section" id="empDynBlocks1Section">
    <div class="collapsible-header" id="empDynBlocks1Header">

    <div class="collapsible-content show" id="empDynBlocks1Content">
        <div class="charts-grid">
            <canvas id="empDynTopBlocks1Chart"></canvas>
            <canvas id="empDynBlocks1DynamicsChart"></canvas>
            <canvas id="empDynBlocks1DistributionChart"></canvas>
        </div>
    </div>
</div>
```

### Новые функции JavaScript:

**js/employee-dynamics-dashboard.js:**

1. **updateBlocks1Analysis(data)**
   - Основная функция анализа блоков 1 уровня
   - Подсчитывает статистику по полю `Block_1_lvl`
   - Вызывает три функции построения графиков

2. **updateTopBlocks1Chart(topBlocks)**
   - Строит горизонтальную столбчатую диаграмму топ-5
   - Использует `indexAxis: 'y'` для горизонтальной ориентации
   - Цвета: 5 оттенков из палитры Golden Fields Glow

3. **updateBlocks1DynamicsChart(data, topBlockNames)**
   - Строит линейный график динамики
   - Группирует данные по датам и блокам
   - Показывает только топ-5 блоков для читаемости

4. **updateBlocks1DistributionChart(blockStats)**
   - Строит кольцевую диаграмму распределения
   - Показывает все блоки 1 уровня
   - Компактная легенда справа

### Глобальные переменные:

```javascript
let empDynBlock1Charts = {
    top: null,
    dynamics: null,
    distribution: null
};
```

- Выборе сотрудника
- Изменении периода дат
- Нажатии кнопки "Обновить"

## Преимущества нового блока

1. **Детальность**: Более глубокий уровень анализа проблем
2. **Визуализация**: Три типа графиков для разных аспектов
3. **Топ-5 вместо топ-3**: Больше информации о проблемных областях
4. **Горизонтальная диаграмма**: Лучше для длинных названий блоков
5. **Кольцевая диаграмма**: Современный вид, экономия места
6. **Согласованность**: Единый стиль с блоками 0 уровня

## Примеры использования

### Сценарий 1: Анализ проблем
Руководитель видит, что у сотрудника высокий процент отклонений:
1. Смотрит Block 0 → "Клиентоцентричность" - основная проблема
2. Смотрит Block 1 → "Процедуры по процессу" - конкретная область
3. Может дать целевые рекомендации по улучшению

### Сценарий 2: Отслеживание прогресса
После обучения сотрудника:
1. График динамики Block 1 показывает снижение отклонений
2. Видно, в каких конкретных областях есть улучшение
3. Можно скорректировать дальнейшее обучение

### Сценарий 3: Сравнение детализации
1. Block 0 показывает общую картину (3 категории)
2. Block 1 раскрывает детали (5+ подкатегорий)
3. Полное понимание структуры проблем

## Адаптивность

- **Desktop**: 3 графика в ряд
- **Tablet**: 2-3 графика в зависимости от ширины
- **Mobile**: 1 график на всю ширину
- Все графики responsive и maintainAspectRatio
