# Функция переключения группировки графиков

## Что реализовано

### 1. Переключатель группировки
- Добавлен новый переключатель "Группировка" рядом с переключателем "Режим отображения"
- Исправлены стили для корректного отображения длинных текстов
- Два режима:
  - **По месяцам** (по умолчанию) - группировка по месяцам, подразделения в легенде
  - **По подразделениям** - группировка по подразделениям, месяцы в легенде

### 2. Макет графиков (исправлен)
- Изменен с 3 графиков в строке на **2 графика в первой строке + 1 график во второй строке**
- Третий график центрирован и занимает **70% ширины** второй строки (увеличено с 50%)
- Улучшено выравнивание переключателей
- Адаптивный дизайн для мобильных устройств

### 3. Логика переключения
- **Режим "По месяцам"**: 
  - Ось X: месяцы (март, апрель, май...)
  - Легенда: подразделения (Гридчина, Мельникова...)
  
- **Режим "По подразделениям"**:
  - Ось X: подразделения (Гридчина, Мельникова...)
  - Легенда: месяцы (март, апрель, май...)

### 4. Файлы изменены
- `index.html` - добавлен переключатель группировки
- `css/styles.css` - обновлены стили для макета и переключателей
- `js/modules/checklist-charts.js` - добавлена логика переключения группировки

### 5. Функции JavaScript
- `toggleChecklistGroupingMode()` - переключение режима группировки
- `generateMonthlyGroupedData()` - генерация данных для группировки по месяцам
- `generateDepartmentGroupedData()` - генерация данных для группировки по подразделениям
- `initGroupingToggleSwitch()` - инициализация переключателя группировки

## Как использовать
1. Откройте вкладку "Детализация по чек-листам"
2. Разверните блок "📊 Динамика блоков по месяцам"
3. Используйте переключатель "Группировка" для изменения режима отображения
4. Используйте переключатель "Режим отображения" для переключения между количеством и процентами
